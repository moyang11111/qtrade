# 决策 / 因子 使用说明

> Qtrade 左栏相关入口：
> - 🎛 决策（底座 Pitch 审批）
> - 🧬 因子库（Qtrade 自己的 35+ 因子）
> - 📊 因子仪表（底座 /factors 因子池面板）

---

## 一、🎛 决策（Pitch 审批）

**它是干嘛的**：底座把“机会池挖掘出的候选股”整理成 Pitch 提案，你在这里做**人工审批**：哪些值得买、哪些否掉。

**怎么用**：
1. 左侧点「决策」。
2. 页面列出提案：股票、动作（买/加）、买入价区间、目标价、止损、置信度、原因。
3. 逐个点「批准 / 否决 / 跳过」。
4. 批准的会进入后续流程：回测 → 远期池跟踪。

**注意**：如果页面是空的/提示未生成，是因为底座的机会池/Pitch 数据管道没跑。要让它有数据，需要先跑底座的扫描/Pitch 流程（或在 Qtrade 项目里运行：
```cmd
python scripts/portal_min_feed.py
```
先给机会池垫一份最小数据，然后决策页能显示样例）。

---

## 二、🧬 因子库（Qtrade 自己的）

**它是干嘛的**：一堆量价/技术因子（动量、反转、波动、量能、RSI、布林等 35+ 个），并给单只股票算出每个因子当天的值。

**怎么用**：
1. 左侧点「因子库」。
2. 上半部分是**因子清单**（因子名 + 中文名 + 含义）。
3. 下方输入/选择**股票代码**，显示该股每个因子的**当前数值**。
4. 看什么：因子值越大/越小代表 stock 当前在哪个维度强/弱，比如 `reversal20` 高=超跌回暖，`rsi_revert` 高=RSI 超卖。

---

## 三、📊 因子仪表（底座因子池面板）

**它是干嘛的**：不针对单只，而是看**整个因子池**的状态——哪些因子现在有用、拥挤、失效，以及因子回测表现（ICIR / 夏普 / 单调性）。

**怎么用**：
1. 左侧点「因子仪表」。
2. 看几个区块：
   - **因子档案**：因子池里有哪些因子。
   - **拥挤度**：哪些因子已被用滥（拥挤=新加入收益小）。
   - **回测汇总**：ICIR/夏普排名前八，挑 ICIR 高、夏普正的因子用。
   - **裁决**：系统对因子的可用性判断。
3. 决策依据：优先用「未拥挤 + 回测稳」的因子，避开拥挤/负收益因子。

**注意**：此页数据来自底座因子池输出（`report/factor_pool*.json`、`data/factorpool/output/…`）。本地可先生成一份：
```cmd
python scripts/factorpool_min_feed.py
```
生成后 `因子仪表` 就有因子面板/档案/拥挤度可看。

---

## 四、它们和「自动模拟交易 / 训练营」的关系
- 因子/决策是**分析层**：帮你选因子、审批候选，不直接下单。
- 自动模拟盘是**执行层**：拿信号引擎（目前演示版双均线，可接 Sequoia/欧奈尔）在模拟资金上撮合、T+1、风控。
- 训练营是**练手层**：猜涨跌/买卖点/复盘，纯练习。
